## [추가] 슬라이드 5-1 (슬라이드 5 뒤) — AI 신뢰성 강화: 2차 판정
- **제목**: 한 번 더 확인하는 AI
- **핵심 문장**: 리허설 사진 119장을 분석해 숨은 오인식을 찾고, 공개 데이터셋으로 막았다
- **본문**
  - 발견: 리허설에서 학습 모델이 **사람 얼굴을 'Metal'로 인식**(신뢰도 최대 0.83) — 하드웨어가 연결되면 사람이 서기만 해도 모터가 움직일 위험
  - 대응: 공개 쓰레기 데이터셋 **TrashNet 2,527장**으로 대규모 사전학습 이미지 모델(CLIP) 위에 재질 분류기를 학습해 **2차 판정기**로 추가
  - 성능(학습에 쓰지 않은 508장): **정확도 91.9%** (유리 93% · 금속 90% · 종이 98% · 플라스틱 84%) — 학습 없이 CLIP만 쓰면 78.1%
  - 효과: 리허설 실사진 119장 중 **얼굴 오인식 92건 차단** · 사람 사진 입력 시 명령·전송 없음
  - 원칙: YOLO가 확신(0.85 이상)하면 그대로, 애매할 때만 보정 · 판정기를 못 쓰면 자동으로 YOLO만 사용
- **시각 자료**: 왼쪽 "YOLO: Metal 0.83 (실제는 사람 얼굴)" 사진 → 가운데 "2차 판정: 배경 0.99 → 무시" → 오른쪽 결과 "모터 동작 없음". 아래에 정확도 막대 2개(78.1% vs 91.9%)
- **발표 멘트**: "리허설 데이터를 보니 모델이 사람 얼굴을 금속으로 착각하고 있었습니다. 재학습할 시간은 없었지만, 공개 데이터셋으로 2차 판정기를 붙여서 이런 오인식을 걸러냈습니다."
- **정직하게 덧붙일 말 (질문 대비)**: "TrashNet은 흰 배경 사진이라 실제 현장 정확도는 이보다 낮을 수 있습니다. 그래서 확신이 높은 결과는 바꾸지 않도록 보수적으로 설계했습니다."
